# Security Policy

## Supported versions

The project has not released a stable version yet. Security fixes are applied to the latest state of `main` and shipped with the next release.

| Version | Supported |
|---------|-----------|
| latest `main` | yes |
| older tags | no |

## Reporting a vulnerability

Do **not** report security vulnerabilities through public GitHub issues.

Instead, use GitHub's private vulnerability reporting on this repository (Security tab -> Report a vulnerability), or contact the maintainer directly.

Please include:

- A description of the issue and its impact.
- Step-by-step instructions or a proof of concept to reproduce it.
- The affected version or commit.

## Response policy

- You will receive an acknowledgement within 7 days.
- Accepted reports are triaged, fixed, and disclosed in the release notes after a fix is available.
- We ask that you give us reasonable time to fix the issue before any public disclosure.

## Scope notes

This application reads memory from the PCSX2 emulator process. Reports about cheating in online services are out of scope: Harvest Moon: Save the Homeland is a single-player title and this tool does not interact with any networked service.
